# 차곡차곡 · 화면 캡처 모음 (기획안 작성용)

앱의 **모든 화면과 상태**를 실제 앱에서 하나씩 눌러 가며 찍은 PNG 모음입니다. **파일 이름이 곧 "지금 어떤 상황인지"** 이고, 아래 표에 화면 설명과 "어떤 동작으로 이 화면이 나오는지"를 적어 두었습니다.

## 이 자료를 볼 때 알아둘 것

- **기준**: Pleos Connect 에뮬레이터(Android Automotive 14, 2560×1440) 실제 화면 캡처. 앱 버전 0.3.3, 촬영 2026-11-15.
- **일러스트**: 지금 화면 속 풍경 그림(호수·들판·노을 등)은 임시 일러스트입니다. 이후 **실사 이미지·영상으로 교체될 자리**입니다. 화면 구성(글자·버튼·위치)을 참고하세요.
- **디자인은 계속 다듬는 중**이라 이후 모습이 조금 달라질 수 있습니다. (다시 찍는 건 쉬우니 필요하면 요청하세요.)
- **홈 기록 버튼(④)** 은 이 에뮬레이터에 카메라가 없어서 카메라 영상 대신 풍경 화면+마이크 소리로 대체해 찍었습니다. 카메라가 있는 차에서는 실제 카메라 영상이 들어갑니다.
- 카드 속 시간·날짜·숫자는 데모 시나리오 값입니다. (예: 오늘의 기록의 "08:57" 같은 시각은 촬영한 순간의 에뮬레이터 시계)

## 앱 한눈에 보기

```
시작 화면 ─▶ 카메라(촬영) ─▶ (썸네일) ─▶ 오늘의 기록 ─┬ 오늘 기록 (카드)
                                                    ├ 한마디
                                                    └ 귀갓길 낭독
                      갤러리(앱의 홈) ─┬ 모아보기 ─ 카드 편집
                                       ├ 영상 보관함
                                       ├ 지도
                                       └ 회상
                      설정(오른쪽 위 아이콘) ─ 기억 이사 / 화질 / 개인정보 / 목업 되돌리기
홈 기록 버튼 ─ 앱 밖(차량 홈)에서도 떠 있는 "눌러서 5초 기록"
상단 "주차 중 ↔ 주행 중 · 음성 모드" ─ 주행 중에는 지도 잠김
```

## 데모 시나리오 (앱을 처음 켜면)

**춘천 당일치기를 마치고 귀가 중(15:20)** 인 하루. 오늘의 기록에 이미 5개의 순간이 쌓여 있다.

| 시각 | 장소 | 일어난 일 |
|---|---|---|
| 08:42 | 우리 집 | 출발 — 주차 브레이크를 풀자 기록이 시작됐어요 |
| 09:25 | 가평휴게소 | 18분 쉬어 감 — 문 네 개가 열렸다가 18분 뒤에 닫혔어요 |
| 10:05 | 의암호 길 | 안개 속을 달림 — 안개등이 켜지고 뒷창문 두 개가 3분쯤 내려갔어요 |
| 12:45 | 춘천 케이블카 | 한마디 남김 — "여기 어땠어요?" 케이블카가 호수 위를 날았어 |
| 15:20 | 귀갓길 | 집으로 출발 — 차가 하루를 읽어 줄 준비를 해요 |
