# 노을 고속도로 주행 영상 최종본

- app-background/highway-driving-15s.mp4: 추가 요청한 15초 연속 주행 배경. UI 없음, 1920×1080, H.264, 30fps, 무음.
- submission/highway-driving-ui-15s.mp4: 같은 15초 영상에 기존 UI를 고정 합성한 시안.
- app-background/highway-driving-5s.mp4: UI 없는 앱용 배경. 1920×1080, H.264, 30fps, 5초, 무음.
- submission/highway-driving-ui-5s.mp4: 기존 버튼·문구·차량 상태 패널을 고정 합성한 제출용 5초 영상.
- submission/chagok-demo-60s.mp4: 기존 시연의 5–10초 촬영 화면만 고속도로 주행 영상으로 교체한 60초 최종본. 나머지 장면과 시간은 유지했습니다.

Higgsfield Seedance 2.5 유료 모드에서 첨부 노을 고속도로 이미지를 참조해 생성했습니다. 실제 차량 촬영이 아닌 AI 주행 시뮬레이션입니다. 앱에서는 배경 영상 위에 기존 실제 UI를 표시하세요. 제공된 UI 합성본은 시연용이며 상태값은 고정입니다. 영상 끝과 시작은 연속 루프가 아닙니다.

최종 배포에는 고속도로 영상만 포함합니다. 도심 생성본은 제외했습니다.
