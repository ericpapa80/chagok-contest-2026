# 개발 범위와 현재 상태

2026-11-15 개발팀이 제공한 현황입니다. APK 실행을 이 자료 제작 과정에서 독립적으로 재검증한 것은 아닙니다.

Kotlin·Jetpack Compose 기반 Pleos Connect 앱으로, v0.3.4 release APK를 Pleos 에뮬레이터(Android Automotive 14, 2560×1440)에서 실행해 확인했습니다.

## 구현 및 확인 범위
- 시작·카메라·오늘의 기록 흐름, 오늘의 기록·한마디·귀갓길 낭독 탭
- 갤러리 모아보기·편집·지도·회상
- 다른 앱 사용 중 카메라 기록 요청 오버레이
- 시연용 주행·주차 상태에 따른 화면 제한
- 도로망 위 경로 및 기억 지점 지도
- 기억 이사·화질·개인정보·목업 환경 복귀 설정

## 실제 연동 전
- 문·창문·안개 등 차량 또는 주변 상태 인식
- 한마디 질문·대답 및 귀갓길 낭독은 고정 시나리오로 동작
- 사용 중인 에뮬레이터 환경에 카메라 입력이 없어 임시 풍경 영상으로 대체

## 향후 계획
Vehicle SDK를 통한 상태 입력과 권한 확인, 음성 SDK를 통한 실제 입력·출력, 권한 거부·재실행 복구·주행 전환 제한·저장 및 삭제·연동 오류 처리를 검증합니다. 지원 상태 항목은 SDK 제공 범위에 따라 확인합니다.

## 제출 자료와 앱 실행의 구분
이 GitHub Pages 자료는 기존 v0.3.3 캡처와 생성 풍경에 기반한 화면 시안입니다. 60초 편집 시연의 5–20초에는 노을 고속도로 AI 주행 영상 15초와 기존 UI를 합성했습니다. 실제 차량 촬영 또는 앱 실행 녹화가 아닙니다.
