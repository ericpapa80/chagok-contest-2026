- GitHub는 제출자료 및 편집 도구 저장소입니다. Android 앱 소스 저장소가 아닙니다.

- 시연은 화면 캡처 기반 편집본이며 실제 앱 실행 녹화가 아닙니다.
- 실사 적용 화면의 일부 카드 글자·형상은 생성 과정에서 원본과 달라질 수 있습니다. 정확한 문구와 UI는 원본 캡처를 기준으로 보세요.
