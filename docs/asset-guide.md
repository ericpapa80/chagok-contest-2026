# 앱 자산 사용 안내

Higgsfield Nano Banana Pro로 만든 개별 실사풍 이미지입니다. 원본 README의 구도·팔레트와 파일명을 참고했습니다.

- 오늘의 기록: PNG 5장, 1080×2386. 각각 3초 MP4.
- 갤러리: PNG 11장, 가로 1080px, 카드별 원본 높이 유지. 각각 3초 MP4.
- 기타: 시작 배경과 카메라 도로 PNG 각 1920×1080. 시작 배경만 8초 MP4.
- 영상: H.264, yuv420p, 30fps, 무음, faststart. 3초 클립은 1.0→1.12배, 시작 배경은 1.04→1.14배의 중앙 확대입니다.
- 확대 영상은 Higgsfield 생성 이미지를 FFmpeg로 편집했습니다. 생성형 영상과 달리 확대율과 재생 시간을 고정했습니다.
- 세로 숏폼의 풍경 움직임에는 Higgsfield Seedance 2.5로 생성한 영상 3편을 사용했습니다.

이미지 하단의 어두운 그라데이션과 앱 제목·설명은 앱 UI에서 별도로 얹으세요. 생성된 풍경은 실제 장소를 정확히 기록한 사진이 아닙니다.

파일: `assets/images/{today,gallery,other}`, `assets/videos/{today,gallery,other}`.
