# 차곡차곡

차를 타고 함께한 순간을 장소와 시간에 연결하고 다시 꺼내보는 차량용 기억 기록 앱의 공모전 제출자료입니다.

[제출자료 보기](https://ericpapa80.github.io/chagok-contest-2026/) · [60초 시연](https://ericpapa80.github.io/chagok-contest-2026/videos/chagok-demo-60s.mp4?v=highway15final) · [40초 숏폼](https://ericpapa80.github.io/chagok-contest-2026/videos/chagok-short-40s.mp4)

완성 자료: 화면 48장(실사 시안 36장 + 원본 유지 12장), 비교용 원본 48장, 개별 이미지 18장, 앱용 확대 영상 17개, 제출용 영상 2개.

영상은 H.264/30fps입니다. 60초 시연은 무음이며, 40초 숏폼은 한국어 내레이션과 잔잔한 배경음악을 포함합니다. 60초 시연은 1920×1080, 숏폼은 1080×1920입니다. 생성 시안의 일부 카드 문구·형상은 원본과 차이가 있을 수 있습니다. 정확한 UI는 비교용 원본을 기준으로 보세요.

## 자료 범위

이 저장소는 화면 시안과 화면 흐름 설명, 소개 영상의 제출용 자료 저장소입니다. Android 앱 소스 저장소가 아닙니다. 실제 차량 연동 또는 완성 APK를 입증하지 않습니다.

화면 원본은 제공받은 Pleos Connect 에뮬레이터(Android Automotive 14, 2560×1440) v0.3.3 캡처 48장입니다. 풍경은 Higgsfield를 이용해 실사 스타일로 만든 연출 이미지입니다. 표시된 경로, 시간, 가족 대화는 데모 시나리오이며 실제 가족의 이동 기록이 아닙니다.

## 핵심 흐름

1. 기록: 카메라와 짧은 영상 기록으로 하루의 순간을 남깁니다.
2. 오늘의 기록: 시간순 카드에서 순간을 열고 제목을 편집합니다.
3. 한마디와 귀갓길 낭독: 장소에 대한 한마디와 하루 이야기를 연결합니다.
4. 갤러리: 모아보기, 영상 보관함, 지도, 회상으로 기억을 탐색합니다.
5. 차량 상태와 설정: 주행 중 지도 잠금, 기억 이사 및 개인정보 설정을 보여줍니다.

세부 화면 설명은 [화면 가이드](docs/screen-guide.md)를 참고하세요.

## 폴더

| 폴더 | 내용 |
|---|---|
| screens | 실사 풍경 적용 화면 시안 |
| assets | 개별 앱 배경 이미지 |
| videos | 가로형 화면 흐름 시연 및 세로형 소개 숏폼 |
| docs | 화면 설명, 구현 상태 및 제출 안내 |
| tools | 자료 정리 및 영상 편집 스크립트 |

## 구현 상태의 해석

제공된 화면은 앱의 여러 상태를 보여주지만, 이 저장소에서 실행 가능한 앱 소스나 실제 차량 연동을 검증한 것은 아닙니다. 시연 영상의 화면 전환은 캡처를 바탕으로 편집한 설명용 흐름이며 실제 입력 이벤트의 실행 녹화와 구분합니다. 실제 앱 프로젝트 및 APK가 확보되면 검증 범위와 실행 방법을 추가할 수 있습니다.

## 개인정보

대표자 정보와 동의·서명 문서는 이 저장소에 포함하지 않습니다. 풍경 이미지는 생성형 AI를 활용한 시안이며 실제 장소의 정확한 모습을 보증하지 않습니다.

## 편집 재현

Windows PowerShell 7, FFmpeg, 맑은 고딕 글꼴이 필요합니다. 저장소에서 `pwsh -NoProfile -File tools/build-submission.ps1`을 실행하면 화면과 `videos/source`의 Higgsfield 생성 클립으로 제출용 영상 2개를 다시 만듭니다. 앱 실행을 위한 빌드 명령은 아닙니다.

## 숏폼 리뉴얼 — 2026-11-15

가상의 한국인 가족이 풍경을 기록하고 한마디를 더한 뒤, 몇 해 후 같은 장소에서 추억을 꺼내보는 40초 세로 콘셉트 영상입니다. Higgsfield Seedance 2.5 유료 1080p로 6초 장면 4개를 생성하고, 기존 고속도로 영상을 함께 편집했습니다. 전체 화면 실사풍 장면과 큰 한글 자막을 사용하며 실제 앱 조작이나 실재 가족의 기록은 아닙니다. 기존 build-submission.ps1은 초기 버전 재현용이므로 최신 영상을 덮어쓰지 않도록 주의하세요.

### 숏폼 오디오 업데이트

Higgsfield Seed Audio 1.0으로 만든 한국어 내레이션을 장면에 맞춰 배치하고, 이 영상용으로 직접 구성·합성한 피아노와 앰비언트 패드 음악을 더했습니다. 외부 음원 샘플은 사용하지 않았습니다. 40초, AAC 스테레오 48kHz이며 영상 장면은 그대로 유지했습니다.

### 20년 후의 결말

어린 시절 노란 카디건을 입었던 아이가 20년 후 엄마가 되어 자신의 아이와 같은 호숫가를 다시 찾는 결말을 추가했습니다. 한국어 내레이션과 오리지널 피아노·패드 음악을 포함한 40초 확장판입니다. 27–29초는 시간 전환과 어린 시절 회상, 29–36초는 다음 세대와의 새 여정, 36–40초는 마무리입니다. 이전에 배포한 chagok-short-30s.mp4 주소도 최신 40초 파일을 제공하는 호환 주소로 유지합니다.
